# 🎬 Movie Rental Analytics Dashboard

## 📌 Project Overview
The **Movie Rental Analytics Project** is a data analytics project designed to analyze movie rental business data and generate meaningful insights using **SQL, Excel, and Power BI**.  
The project focuses on understanding customer behavior, rental trends, revenue performance, and movie popularity to support data-driven business decisions.

---

## 🛠️ Tools & Technologies Used
- **SQL** – Data extraction, joins, aggregations, and business queries  
- **Microsoft Excel** – Data cleaning, preprocessing, and validation  
- **Power BI** – Interactive dashboards and data visualization  

---

## 📊 Key Features & Insights
- 📈 **Revenue Analysis** – Track total revenue, rental income, and trends  
- 🎥 **Popular Movies Analysis** – Identify most rented and top-earning movies  
- 👥 **Customer Analysis** – Analyze active customers and rental frequency  
- 🕒 **Rental Trends** – Monthly and yearly rental performance  
- 🏬 **Store Performance** – Compare performance across stores  

---

## 🧩 Dashboard Highlights
- Interactive filters (date, customer, movie category)
- KPIs for total rentals, revenue, and customers
- Visuals including bar charts, line charts, and tables
- Business-friendly insights for management decision-making
